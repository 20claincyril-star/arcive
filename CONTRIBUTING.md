# Contribuer a Arcive

## Prerequis

- Node.js 20+
- npm 10+

## Workflow

1. Fork + branche de feature
2. Implementer avec tests
3. Executer:
   - `npm test`
   - `npm run build`
   - `npm run lint`
4. Ouvrir une Pull Request avec contexte, impact, plan de test

## Standards

- TypeScript strict
- Commits atomiques
- Pas de secret dans le code ou les fixtures
- Toute regression de securite bloque la PR
